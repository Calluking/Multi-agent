# Contributing

Thanks for contributing to Multi-Agent Contract Protocol.

## Development

```bash
npm install
npm test
npm run check
```

Keep changes focused, add a regression test for behavior changes, and update the relevant documentation or validation report. Do not commit benchmark secrets, local memory stores, generated `dist/` output, or agent workspace artifacts.

## Pull requests

Describe the problem, the contract or lifecycle behavior changed, tests run, and any compatibility implications for CLI adapters.
