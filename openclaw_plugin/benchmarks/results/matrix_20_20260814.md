# 20-task matched benchmark matrix (2026-08-14)

This report compares the same model, task text, runner, and evaluator with the
Multi-Agent Contract Protocol (MACP) disabled and enabled. It contains compact
scores and provenance only; raw model transcripts, credentials, temporary
workspaces, and Docker state are intentionally excluded from the repository.

## Results

| Benchmark | MACP off | MACP on | Delta |
| --- | ---: | ---: | ---: |
| CooperBench official pair pass rate (20 pairs) | 5/20 (25%) | 14/20 (70%) | +45 pp |
| MultiAgentBench mean task score (20 tasks) | 4.15/5 | 3.2375/5 | -0.9125 |
| MultiAgentBench normalized score | 83.0/100 | 64.75/100 | -18.25 |
| MultiAgentBench runs producing `solution.py` | 20/20 | 11/20 | -9 |

CooperBench pair transitions were: nine failures became passes, five remained
passes, six remained failures, and no passing control regressed.

MultiAgentBench dimension means:

| Dimension | MACP off | MACP on | Delta |
| --- | ---: | ---: | ---: |
| Instruction following | 4.25 | 2.50 | -1.75 |
| Executability | 4.80 | 3.90 | -0.90 |
| Consistency | 3.60 | 3.30 | -0.30 |
| Quality | 3.95 | 3.25 | -0.70 |

## Interpretation

MACP substantially improved explicit two-owner integration in CooperBench. It
did not generalize to the lightweight autonomous MultiAgentBench adapter in
this revision: nine coordinators exited successfully without writing the
required final deliverable. Those missing deliverables remain in the score and
were not discarded as timeouts.

The split result indicates that the contract gates work well when the task has
explicit peer ownership and an integration artifact, but the lifecycle policy
is too permissive when subagent use is optional and the only required artifact
is `solution.py`.

## Public-data policy

The repository includes runners, runbooks, frozen case selection, aggregate
scores, and methodology. Raw agent conversations and generated workspaces are
kept local because they are large and may contain environment-specific paths or
provider metadata. `.env*`, logs, stdout/stderr, run directories, and experiment
directories remain ignored.
