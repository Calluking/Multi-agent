# Official CooperBench 3×2 adapter smoke run — 2026-08-11

## Controlled settings

- Official CooperBench source and native `cooperbench run` / `cooperbench eval`
- Setting: `coop`
- Backend: Docker
- Agent adapter: `macp_openclaw`
- Model: `deepseek/deepseek-v4-flash`
- Task concurrency: 1
- Two official peer agents per task

All twelve peer executions submitted non-empty patches. The official evaluator applied both patches for every task. Task 26 merged cleanly but failed compilation because the merged changes referenced missing cross-feature symbols. Tasks 56 and 2068 reached the official evaluator but had merge conflicts.

## Validity finding

The three without-plugin runs are valid baseline observations for this adapter and subset.

The three enabled runs are **not valid measurements of MACP effectiveness**. MACP was installed and configured, but the shared store remained empty. Official CooperBench starts peers as independent top-level containers, while the current plugin derives contracts from an OpenClaw coordinator's `TASK.md` and parent→child lifecycle. Consequently, these enabled runs behaved like ordinary OpenClaw peers.

Do not publish this as a 0% versus 0% plugin comparison. The next adapter revision must bootstrap a common official run/assignment identity into MACP before agent execution and prove non-empty dependency, co-domain and testing banks.
