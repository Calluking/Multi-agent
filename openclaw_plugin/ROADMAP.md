# Roadmap

## Near term

- Publish a stable adapter interface for additional CLIs.
- Add a standalone CLI adapter example.
- Improve co-domain benchmark semantics and evaluator coverage.
- Add machine-readable run reports.

## Longer term

- Define the Multi-Agent Contract Protocol interchange format.
- Add durable backends beyond filesystem memory stores.
- Provide observability dashboards for contract state and recovery ownership.
- Establish cross-runtime compatibility tests.
